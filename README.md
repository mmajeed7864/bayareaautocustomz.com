# Bay Area Auto Customz

Production static site for Bay Area Auto Customz, deployed at [bayareaautocustomz.com](https://bayareaautocustomz.com/).

## Structure

- `index.html` contains the landing page markup.
- `styles.css` contains the visual system and responsive layout.
- `app.js` contains the designer, booking handoff, gallery, reels, and chatbot logic.
- `images/` contains the approved media assets used by the site.

## Notes

- The site is intentionally static and does not send form submissions to a backend.
- Quote requests are handed off through the on-page contact actions.
- Customer-facing pricing remains quote-only.
